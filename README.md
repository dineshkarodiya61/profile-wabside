# Durgesh Kumar - Portfolio Website

Personal academic portfolio website for Durgesh Kumar - LLM Researcher.

## Features
- Responsive design with Bootstrap
- Dark/light theme toggle
- Search functionality
- CV, Publications, Projects pages

## Technologies
- HTML5, CSS3, JavaScript
- Bootstrap 5
- Font Awesome 6
- Academicons

## Setup
1. Clone the repository
2. Add your profile photo to `img/dk.webp`
3. Add your CV to `CV/cv.pdf`
4. Open `index.html` in your browser
